# ห้องทดลองสถานะสาร

สื่อการสอนวิทยาศาสตร์ ป.5 เรื่อง **การเปลี่ยนสถานะของสาร** เปิดได้ทั้ง iPad มือถือ และคอมพิวเตอร์

**เปิดใช้งาน:** https://atpsp16.github.io/state-change-lab/

มี 4 โหมด เล่นต่อกันได้

1. **ตู้เย็นมหัศจรรย์** ลากน้องน้ำแข็งไปช่องแช่แข็ง กลางแดด หรือเตาร้อน ดูการหลอมเหลว แข็งตัว ระเหย และเดือด
2. **โฮโลแกรม** ภาพอนุภาค 4 ด้านสำหรับพีระมิดพลาสติกใสวางบน iPad มีปุ่มร้อนขึ้นและเย็นลง และปุ่มเต็มจอ
3. **โฮโลแกรมแบบกล่อง** ภาพเดียวเต็มจอสำหรับวางมือถือคว่ำบนกล่องที่มีแผ่นใสเอียง 45° มองจากด้านหน้า ภาพเปลี่ยนสถานะวนไปเอง
4. **AR** แบบจำลองอนุภาคลอยบนภาพจากกล้องสด ลากย้าย ถ่างนิ้วย่อขยาย และเก็บภาพได้

ทั้งหมดอยู่ในไฟล์ `index.html` ไฟล์เดียว ไม่ต้องติดตั้งอะไร
